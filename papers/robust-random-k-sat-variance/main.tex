\begin{abstract}
Fix an integer $k\ge 3$.  For each $n$, consider an independent, not
necessarily identically distributed stream of proper signed $k$-clauses on
$n$ Boolean variables.  Suppose that every clause law is bounded above and
below, pointwise, by fixed constant multiples of the uniform proper-clause
law.  We prove that the first unsatisfiable prefix $H_n$ satisfies
\[
    \Var(H_n)=O(n),
\]
uniformly over all such streams.  The same bound holds for $H_n$ clipped at
any fixed linear time horizon.  The argument robustifies the clause-omission
and root-test method developed for uniform random $k$-SAT and the killing
potential introduced for the sharp three-literal variance bound.  The main
new ingredients are a general-$k$ potential inequality with exponent
$k/(k-1)$ and a conditional-density analysis showing that nonuniform root
tests contribute only an exponential factor in a root-incidence count with
uniformly bounded exponential moments.  We also isolate a strictly more
local robustness criterion: global pointwise upper comparison can be replaced
by conditional test-density and root-incidence bounds.  No stationarity in
the clause laws is required.
\end{abstract}
